# Flood-Fill---Grupo02-bcs4
Projeto educacional associado a matéria de Resolução de Problemas Estruturados em Computação, onde há a implementação do algoritmo Flood Fill, semelhante à ferramenta balde de tinta. O programa receberá uma imagem, uma coordenada inicial e uma nova cor. A região conectada que possuira mesma cor do pixel inicial deverá receber a nova cor.
